然后我发现了TiebaLite ，虽然停更了，但依旧是神（希望百度能学学）

# 这是什么？

**TiebaLite** 是GitHub上的一个开源项目，贴吧的第三方轻量客户端，Flutter写的，安装包只有4MB左右。

**零广告**：开屏没有"摇一摇跳转"，信息流没有 sponsored content，评论区干干净净**极度轻量**：内存占用比官方低一大截，5年前的老安卓都能流畅刷帖**省流量**：图片懒加载+压缩，一个月能省不少流量**OLED纯黑模式**：屏幕黑的纯粹，屏幕完全不发光的黑（OLED屏幕才支持）**多账号切换**：很适合有大小号的用户，一键切换不用重新登录

界面就是极简风，只有"首页、动态、消息、我的"三栏，没有直播、没有短视频、没有游戏中心，就是纯粹的刷帖体验。

# 现状说明（重点）

**这个项目已经于2024年2月17日正式停更了**，作者"幻城"在GitHub设为归档状态（read-only）

目前最后版本是 **3.8.3**（2020年发布的），虽然4年过去了，但核心功能还能用，基本的浏览、回帖、签到都没问题。不过随着官方API变动，部分次要功能（比如某些新特性的支持）可能会有点小毛病，这点得有心理准备

# 能用多久？值得装吗？

如果你：

-   受够了官方App的臃肿和广告

-   只是单纯想刷帖、看回复、签到

-   有一台备用机或者老设备想省资源

那TiebaLite依旧是**安卓端最好的贴吧第三方客户端**，没有之一。

但如果你需要：

-   最新的贴吧功能（比如某些新出的互动玩法）

-   完全稳定的长期支持（毕竟停更了）

那可能还是得回去用官方，或者期待有其他开发者接手（目前看 Fork 了300多个，但好像没看到有继续维护的分支）
