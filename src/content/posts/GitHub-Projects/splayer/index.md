找了个开源的音乐播放器，界面挺好看的，功能也够用，分享一下。

**SPlayer** 是基于 Vue3 + Electron 开发的桌面端播放器，支持 Windows / macOS / Linux。

**主要功能：**

**Modern UI** - 毛玻璃效果、动态背景、流畅动画，支持自定义主题色和暗黑模式

**多平台支持** - 支持网易云账号登录，歌单、收藏、会员权益同步

**基础功能齐全** - 搜索、歌单、专辑、歌手、电台、MV、歌词显示都有

**本地音乐** - 也能导入本地音乐文件，当个本地播放器用

**跨平台** - Win/Mac/Linux 界面统一，换系统不用重新适应

**技术细节：**

-   Vue3 + Vite + Electron 架构
    

-   响应式设计，窗口大小随便调
    

-   支持 UnblockNeteaseMusic 插件（需自行配置）
    

-   GitHub 开源
    

**实际体验：**

启动速度快，内存占用低，界面干净打开就是歌。每日推荐、私人 FM 这些核心功能都在。

**缺点：**

-   需要账号登录，游客模式功能有限
    

-   部分新功能可能没有官方客户端全
    

-   下载功能受限，主要播放在线
    

-   偶尔 API 变动需等更新
